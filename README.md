# Physis
Physis is a physics simulator with a dedicated physics and rendering engine.  Its purpose is to provide an educational demonstration of well-known physical laws, and its module architecture allows client applications to customize the simulated physics.  Its name is derived from the Greek term _[physis](https://en.wikipedia.org/wiki/Physis)_, which is typically translated into English as "nature".
